Core Game Logic (กลไกการเล่น)
The Core (ฐานแม่): จุดเริ่มต้นที่พิกัดปัจจุบันของคุณ (หรือจุดพิกัดสมมติในห้อง)

Energy Path (รัศมีการปักเสา): * คุณจะปัก "เสาพลังงาน (Pylon)" ต้นถัดไปได้ ก็ต่อเมื่อมันอยู่ในรัศมี (เช่น 100 เมตร) ของเสาต้นก่อนหน้าเท่านั้น

ระบบจะลากเส้นเชื่อม (Polyline) ระหว่างเสาโดยอัตโนมัติ เพื่อแสดง "Grid" พลังงานของคุณ

Troop Deployment (การส่งทหาร):

ทหาร (Units) จะวิ่งไปตาม "เส้นทางเสา" ที่คุณปักไว้เท่านั้น

ถ้าเสาต้นไหนถูกศัตรูทำลาย "เส้นทาง" จะขาด และทหารที่อยู่ปลายทางจะสูญเสียพลังงาน

Strategic Points: บนแผนที่จริงจะมี "Node พิเศษ" (เช่น สี่แยก หรือร้านค้า) ถ้าคุณปักเสาไปคลุมจุดนั้นได้ จะได้โบนัส Energy เพิ่มขึ้น
